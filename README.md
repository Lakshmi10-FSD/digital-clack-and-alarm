# 🕒 Digital Clock + Alarm

A simple and modern **Digital Clock with Alarm feature** built using **HTML, Tailwind CSS, and JavaScript**.
This project displays real-time time and allows users to set, clear, and stop alarms with sound.

---

## 🚀 Features

* 🕐 Live Digital Clock (updates every second)
* ⏰ Set Alarm for a specific time
* 🔔 Alarm Sound Notification
* ⏹ Stop Alarm Button
* 🗑 Clear Alarm Option
* 🌙 Light / Dark Mode Toggle
* 📅 Displays Current Date
* 💬 Status Messages for user actions
* 📱 Responsive and clean UI using Tailwind CSS

---

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* JavaScript (DOM Manipulation)

## ▶️ How to Run

1. Download or clone the repository
2. Open the `index.html` file in your browser
3. View the live clock
4. Set an alarm using the time input
5. Enjoy the alarm with sound 🎵

---

## 💡 How It Works

* `setInterval()` updates the clock every second
* JavaScript `Date()` is used to get current time
* Alarm time is stored and compared with current time
* When matched, alarm sound plays automatically
